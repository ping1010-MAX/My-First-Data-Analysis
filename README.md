# 泰坦尼克号生存数据可视化分析

基于 Python、Pandas 和 Matplotlib 的泰坦尼克号生存数据可视化分析项目。

## 🛠️ 技术栈
- **语言**：Python
- **数据处理**：Pandas
- **数据可视化**：Matplotlib

## 💡 核心分析结论
1. **性别与生还率**：女性生还率远高于男性（符合“女士优先”救援原则）。
2. **船舱等级与生还率**：一等舱生还率最高，三等舱最低，表明社会地位与逃生概率高度相关。

## 📁 仓库文件说明
- `py2.py`：主程序，包含数据读取、缺失值处理、分组聚合与图表绘制。
- `Titanic.csv`：分析所使用的原始数据集。
